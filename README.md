# BH3-ElysianRealm
适用于Deepseek的崩坏3往世乐土角色扮演聊天，十三个剧情角色的AI人设+世界观背景。角色可在保持人设的情况下，正常按要求工作

# 崩坏3 · 往世乐土｜逐火十三英桀 AI 人设包
十三个角色，可以对话，也可以让他们帮你干活。
每人有自己的脾气、底线、说话方式、记得的事，十三个人互相认识。
你点名谁，谁就用第一人称跟你说话。

# 下载后先读这个
请先看 压缩包内的 使用说明.txt 。

# 安装与使用（DeepSeek / DSH 用户）
本包为 DeepSeek 用户（DSH / DeepSeek Harness）设计并测试。

# 安装
1. 点右上角绿色 Code → Download ZIP
2. 解压到任意空目录
3. 用 DSH 打开这个目录本身 
不需要装任何东西，全是纯文本。

# 使用
直接对话就好

# 让他们干活
例如：
    维尔薇，帮我写一下xxx。

他们会一边按自己的性子说话，一边真把事情做掉，成果放在 工作\ 里。
谁都有可能拒绝，但可能性很小。

# 确认装对了没有
以问答形式测试一下角色性格

如果开始长篇解释、照顾你情绪、说话像客服，那是规则没读到，
检查是不是没用这个文件夹当工作区打开。

# 非 DeepSeek 用户
文件为纯文本，别的工具也能用，关键是规则文件名。
把 AGENTS.md 复制一份改成你的工具认的名字，内容一个字不用动，由于不同AI模型之间的差异，不保证能完全正常使用。
不支持自动加载的工具，不建议使用此包
注意：已有自己的规则文件时不要覆盖，尽量选择新开一个工作区使用，放一起可能会出现问题。

# 效果边界
档案 100% 一致；具体回答不会一模一样，取决于模型、你的规则、工具版本、你怎么问。
承诺「同一个角色」是合理的，承诺「一模一样的回答」不是。
